# Sistema de Gestión de Blog Personal - Frontend

Aplicación desarrollada en React con Vite y Tailwind CSS.

## Requisitos Previos

* Node.js (versión 18.x o superior)
* Servicio Backend del TP Integrador N° I en ejecución en 'http://localhost:3000'
* Base de datos MySQL configurada y conectada al Backend

## Instrucciones para Levantar el Proyecto

1. Clonar el repositorio e ingresar a la carpeta del proyecto:
   https://github.com/VaninaCodes/trabajo-practico-integrador-2.git
   cd trabajo-practico-integrador-2

2. Instalar las dependencias necesarias:
   npm install

3. Iniciar el servidor de desarrollo:
   npm run dev

La aplicación estará disponible y accesible en el navegador en `http://localhost:5173`.
